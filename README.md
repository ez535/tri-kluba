# Три клуба

Футбольная игра: назовите игрока, который выступал за все три клуба. Пять раундов с клубами и финальный раунд, где нужно угадать футболиста по подсказкам.

- **Прототип тренировки с ботом:** https://ez535.github.io/tri-kluba/ (файл `index.html`).
- **Игра с друзьями** (`app/`): комнаты до 8 человек по коду или ссылке, в браузере и как Telegram Mini App, бот для групповых чатов.

## Устройство

| Папка | Что внутри |
|---|---|
| `app/game` | Игровой движок: проверка ответов, очки, тройки клубов, финальный раунд |
| `app/server` | Сервер: комнаты по WebSocket, база SQLite, вход и бот Telegram. Без внешних библиотек, нужен Node 22.13+ |
| `app/web` | Клиент для браузера и Telegram |
| `app/data` | База игроков (собирается из прототипа: `npm run data`) |
| `app/test` | Тесты, включая матч вчетвером от лобби до итогов: `npm test` |
| `deploy` | Установка на сервер, автообновление, копии базы — см. [deploy/README.md](deploy/README.md) |

Запустить у себя: `cd app && npm start`, затем открыть http://localhost:8080.
